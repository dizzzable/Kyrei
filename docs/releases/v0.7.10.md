# Kyrei v0.7.10 — evolution control plane, end to end

This patch completes the proposal-first evolution subsystem: a candidate can now
travel the full lifecycle — harvested from live sessions, scored by an offline
evaluator, and promoted into a real artifact with a reversible rollback — while
staying gated, redacted, and human-reviewed at every step.

## Evolution: full harvest → evaluate → promote cycle

- **Harvest** turns idle-tick session digests into candidate drafts: reliability
  hints for repeated tool failures and heal handoffs, and skill playbook drafts
  for orphan failure patterns. Nothing mutates; observations are journaled for
  review.
- **Enriched skill drafts.** A harvested playbook now carries a sanitized name
  and a ready SKILL.md body, so promotion creates a real skill instead of
  rejecting a content-less draft.
- **Evaluate** scores pending candidates with a cheap worker model behind a cost
  ceiling, writing verdict receipts and moving candidates to approved or
  rejected. Candidate text is treated as untrusted data; embedded instructions
  are not followed.
- **Promote + roll back.** An approved candidate deterministically mutates its
  target (owned skill or non-reserved prompt profile) using a two-phase apply
  that snapshots prior state before touching anything. Rollback restores the
  prior content or removes a created artifact.
- **Guards.** Built-in profiles such as `kyrei-main` are never overwritten;
  read-only skills are never mutated; `memory-ranking` and `reliability-hint`
  targets are reported as unsupported rather than applied silently. Every stage
  is gated by config and fails closed when a stage is disabled.

## Settings and review

- `EvolutionSettings` exposes harvest, evaluation, and promotion controls,
  including an editable promotion mode (off / manual / low-risk-canary).
- The Memory Atlas inspector shows evaluation rationale and offers promote and
  roll-back actions, with server-generated executor receipts.
- English and Russian catalogs stay in lockstep for all new strings.
