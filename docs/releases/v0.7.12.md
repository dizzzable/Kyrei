# Kyrei v0.7.12 — 🛡️ the agent stops losing things

This release is the outcome of auditing Kyrei against itself: several swarms of
review agents went through the subsystems, then through the resulting diff. The
most valuable pass was the last one — reviewing our own changes found that two
fixes were dead code and a third had broken its neighbour. Everything below was
reproduced before it was fixed.

## 🩹 Data that used to disappear

- **Codex sessions no longer forget everything.** When `thread/resume` failed —
  a Codex restart, an expired thread — the connector silently opened a fresh,
  empty one. Because that path never sends `messages`, Codex's own thread *was*
  the conversation, so this was total invisible amnesia mid-session. The dead
  thread id is now dropped immediately and the replacement is seeded with the
  transcript.
- **A state file we merely failed to read is no longer overwritten.** A
  transient antivirus or indexer lock made `state.json` unreadable; the next
  flush then wrote empty state over it and every session was gone. Kyrei now
  refuses to write at all until it has read successfully.
- **A lost flush is no longer lost.** The atomic rename fails with `EPERM` on
  Windows whenever another process holds the file for a moment. That silently
  discarded the newest messages. It now retries briefly.

## 🔐 Security

- `GET /api/file` served `.env`, `kyrei-secrets.json` and every other protected
  path verbatim. The workspace jail only proves a path is *inside* the
  workspace; `protectedPaths` was enforced on writes alone.
- Path completion enumerated the workspace's **parent** directory when the
  engine bundle was unavailable. All three file endpoints now share one guard
  that also rejects UNC, device and drive-relative targets.
- `mcp_call` executed with **no approval prompt** in a session with no
  workspace, and "Always allow" on a single MCP call granted every tool on every
  configured server. Approval is now scoped to `server:tool`.
- Memory writers bypassed `protectedPaths`, and `memory_write_notes` was
  ungated entirely — while `MEMORY.md` is read back into the system prompt every
  turn. All three are now gated and secret-scanned.
- A failing command leaked its entire output — up to 512 KB, unredacted, with
  any secret it printed — straight into the model's context. Failures now obey
  the same budget and redaction as successes.
- Interpreter approval no longer falls to `node -p`, `bash -lc`, `cmd /c`,
  `powershell -enc` or `git -C … push`.

## 🧭 A better coding agent

- **`read_file` reads line ranges.** Files no longer arrive whole-or-nothing at
  a 250 000-character limit. Ranged output is line-numbered, so a grep hit and a
  read finally share one coordinate system.
- **`grep_search` returns context lines**, so judging a match no longer costs a
  full file read. Context never consumes the match budget.
- **`grep_search` survives a broken symlink.** ripgrep exits 2 on any unreadable
  file *after* printing its matches; Kyrei treated that as fatal and lost search
  for the rest of the session.
- **`edit_file` explains a malformed patch** instead of reporting a security
  denial that sent the model off to fix a path that was never wrong.
- **`web_fetch` pages long documents** and says which characters it returned.
  Plain-text and JSON pages previously reported a document size that was really
  just the size of the window.
- Fetched code blocks keep their line breaks and indentation, so a command block
  copied from documentation is still runnable.
- MCP failures show what the server actually said instead of `error: unknown`,
  and the tool catalog is fetched concurrently instead of one server at a time.

## ⚙️ Settings that do what they say

- Rejected settings are now visible. A value the validator refused was replaced
  by a default and reported only to a log the user never sees.
- One malformed entry in a list no longer deletes its neighbours.
- Capacity strategy reaches the account pool that can actually act on it.
- `turbo` no longer ignores an explicit allow rule that `auto` honours.
- Long operations — installing GBrain, reindexing, evaluating candidates — are
  no longer aborted after 30 seconds while the server keeps working.

## 🚀 Interface

- Streaming code blocks no longer freeze on their first character.
- The scroll anchor is no longer measured on every token; long transcripts stay
  responsive.
- Up-arrow input history works again.
- A single malformed message no longer blanks itself for the rest of the
  session.
- Compact density now actually changes message spacing.

## 🧪 Testing

`jsdom` and Testing Library are in place, so renderer components are tested by
rendering them rather than by matching regexes against their source — a form
that breaks on a rename and passes on dead code. Anthropic thinking, Bedrock
reasoning and platform-hosted Claude pricing all gained real coverage; several
existing assertions were strengthened after review showed they would pass with
the fix removed.

**Note on platform pricing:** Claude served through Bedrock or Vertex now
resolves to a price and a context window instead of zero, which is what made
dollar budgets silently inert there. Partner rates differ from first-party, so
that figure is an approximation — a budget guard on a close number is worth more
than one that never fires.
