# Kyrei v0.7.11 — the Memory Atlas becomes a real graph

This patch rebuilds the Memory Atlas on two fronts: a new 3D force-directed
view alongside the existing 2D map, and a richer underlying graph so the nodes
actually connect into a web instead of a shallow containment tree.

## 3D graph view

- A new 3D mode renders the memory graph as a force-directed layout with real
  physics — clusters spread apart, hubs read as larger, and the camera focuses
  the node you click or select in the tree.
- Hovering or selecting a node keeps it and its neighbours at full strength and
  dims every other node, so a single memory's connections are easy to trace.
- Toggle between 2D and 3D from the graph toolbar. The choice is remembered per
  workspace.
- The 3D renderer loads lazily — its WebGL bundle is only fetched the first time
  you switch into 3D, so startup stays light for anyone who never opens it. If
  that bundle ever fails to load, the view falls back to the 2D map instead of
  taking the panel down.

## A denser, more useful graph

- **Semantic links.** Memory notes, documents, decisions, plans, handoffs, and
  session records are now connected by similarity: each node links to its
  nearest neighbours above a confidence threshold. This runs on a purpose-built
  offline embedder, so it is deterministic and adds no network cost regardless
  of how the memory index is configured.
- **Evolution links.** An evolution candidate that targets a skill now links to
  that skill's node, in addition to its existing project-root edge.
- Both new edge types stay within the existing graph size budget: semantic links
  only take the room structural edges leave behind, so they can never displace a
  structural edge or make the snapshot report itself as truncated.
- The 2D map now also draws these semantic links (previously they were hidden),
  and both views share one consistent node-colour palette that tracks the active
  theme.

## Release integrity

- `package.json` and both root version fields in `package-lock.json` are now
  `0.7.11`.
- `npm run gate` verifies these fields remain aligned before typechecking and
  tests.
- The 3D graph library (`react-force-graph-3d`, with `three`) is bundled into
  the renderer by Vite and is not shipped a second time inside the packaged
  application; `npm audit --omit=dev` reports no vulnerabilities in shipped code.

## Verification

Engine and renderer typechecks pass; the full Vitest suite passes with no
failures; the engine bundle rebuilds cleanly.

## Update

Install through Kyrei's updater when it offers v0.7.11, or download the platform
artifact from the GitHub Release. Existing sessions, provider configuration, and
local workspace data remain in place.
